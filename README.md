## 🚀 Projetos em destaque

### 🛍️ Niu Modas
**Sistema desktop para cadastro e gestão de clientes.**

Aplicação criada para praticar desenvolvimento de software em um cenário real de negócio, com foco em cadastro de clientes, persistência de dados e integração com API externa.

**Stack:** Python · PySide6 · SQLite · SQL · ViaCEP

**Destaques:**
- CRUD de clientes
- banco de dados SQLite
- validação de CPF duplicado
- consulta automática de endereço por CEP
- interface desktop
- separação entre aplicação e persistência

🔗 [Ver projeto](https://github.com/aavpires93/niu-modas)

---

### 📱➡️💻 CapSendFlow
**MVP para transferência de vídeos grandes do celular para um computador pela rede local.**

Projeto criado para validar uma hipótese técnica relacionada ao fluxo de trabalho de produtores de conteúdo que precisam mover arquivos grandes com rapidez.

**Stack:** Python · FastAPI · HTML · JavaScript · HTTPS

**Destaques:**
- API REST para upload de arquivos
- frontend com barra de progresso
- transferência pela rede local
- geração de certificado HTTPS para ambiente de testes
- tratamento de uploads grandes

🔗 [Ver projeto](https://github.com/aavpires93/CAPSENDFLOW)

---

### ✈️ WhatsApp Travel Agency Bot
**Bot de qualificação de leads para agências de viagens.**

Automação que conduz uma conversa estruturada, coleta dados da viagem e gera um lead organizado para continuidade por atendimento humano.

**Stack:** Python · Selenium · JSON · automação web

**Destaques:**
- máquina de estados para controlar a conversa
- coleta estruturada de destino, datas e quantidade de pessoas
- persistência simples de leads
- recuperação automática de sessão
- tratamento de mensagens repetidas

> Projeto educacional usando automação do WhatsApp Web. Para produção, a evolução prevista é o uso da API oficial do WhatsApp Business.

🔗 [Ver projeto](https://github.com/aavpires93/Whatsapp-travel-agency-bot)
